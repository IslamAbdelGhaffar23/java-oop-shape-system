Object-Oriented Shape Management System (Java)

Overview
An academic project developed in Java using NetBeans, implementing core Object-Oriented Programming (OOP) principles, UML class diagrams, file input/output handling, and a simple GUI component.

Features
- UML Implementation: Converts standard class diagrams into robust Java classes utilizing abstract classes, inheritance, and interfaces (Drawable).
- File I/O: Reads shape configurations (such as circles and cubes) from an input.txt file and exports calculated total area summaries to sumAreas.txt.
- GUI Drawing: Utilizes Java Swing and Graphics to render geometric shapes visually.

Technologies Used
- Java
- NetBeans IDE
- Object-Oriented Programming (OOP) principles
- Java Swing / File I/O
